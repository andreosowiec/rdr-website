# RDR - Website README file.
About: on this file will be writen the instructions and requirements for the project installation, maintenance etc...

# Requirements 
* Check node v24 or ++ 
```
node -v
```
* Check if npx is installed
```
npx -v
```

# Creating project sequence 

Create the project with React and framework Next.js. 
* The "." means that the project has to be installed on the current directory.
```
npx create-next-app@latest .
```

# Run the project
```
npm run dev
```
